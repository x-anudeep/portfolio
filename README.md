# Anudeep Cherukupalli — Interactive Portfolio

Anudeep’s AI and backend engineering portfolio, built with TypeScript, Three.js, GSAP, SCSS, and Vite. Includes professional experience, education and certification, twelve GitHub projects, direct contact links, and a downloadable resume.

## Run locally

Requires Node.js 22.12+ and npm.

```sh
npm ci
npm run dev
```

Open the Local URL printed by Vite. The scene debug panel is available only in development with `?debug`.

## Check and build

```sh
npm run check
npm run build
npm audit
```

`dist/` is generated by the build. `node_modules/` and `dist/` are ignored by Git. No API keys or server credentials are required. Contact links open LinkedIn, GitHub, an email app, or a calling app.

## Hosting

For direct upload, run `npm run build` and upload the generated `dist/` folder to your static host, such as Netlify Drop. Connect a domain you own through the hosting provider’s domain settings.

The included GitHub Pages workflow publishes `x-anudeep/portfolio` from the `main` branch. In repository Settings → Pages, select GitHub Actions. The workflow builds with `VITE_BASE_PATH=/portfolio/`; local development uses `/`.

```sh
VITE_BASE_PATH=/portfolio/ npm run build
```

Canonical metadata currently uses `https://x-anudeep.github.io/portfolio/`. After choosing a custom domain, update the canonical metadata in `index.html` and `privacy.html`, `public/robots.txt`, `public/sitemap.xml`, and `scripts/check-seo-build.mjs` together.

Third-party attribution is preserved in `THIRD_PARTY_NOTICES.md`. Dependency licenses remain applicable.
